人物上限由 130 调至 200，以支持 140 级学习条件。选定的 28 个技能保留原有 1～10 级记录与动画，补足 11～15 级 Tech；只有原本十级上限且已经达到第六/七职阶的对应职业开放十五级。七张原生技能经验表保留 1～13 级阈值，补入有限的 14/15 级阈值及 16 级终止标记。并未让所有职业任意学习所有技能。
