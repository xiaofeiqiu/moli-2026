# 自动加点师

NPC 位于圣殿：地图 `60003`，坐标 **24,34**，名称“自动加点师”，从南侧 **24,35** 接近。法兰城东门医院附近 **223,85** 的“圣殿传送石”可进入。新地图需要正常重启服务端后加载；原生地图检查确认 NPC、传送石及落点没有重叠，房间内通路连通。

## 使用

1. 与自动加点师对话，选择“人物”或携带栏中的某只宠物。随身五栏和银行五栏都可分别配置；选择「配置银行宠物」进入银行列表。银行列表提供返回入口。
2. 选择“全加体力 / 力量 / 强度 / 速度 / 魔法”，或者选择“自定义五项比例”。选择或保存方案后自动开启。
3. 自定义按 **体力、力量、强度、速度、魔法** 顺序输入五个整数，用空格分隔。例如 `1 2 0 1 0` 表示按 `1:2:0:1:0` 分配。每项范围 `0–100`，合计必须在 `1–100`。
4. 可以单独关闭人物或某只宠物的自动加点；再次开启时继续使用已保存的比例。

新角色、新宠物默认关闭。只分配启用后升级新增的点数，原有剩余点数保留；不会洗点。比例的整数舍入进度也会保存，跨等级累计维持比例。

人物遵守已有快速加点脚本的单项上限：`15 + 2 × (等级 - 1)`。当一个属性达到上限时，继续按其他已选择属性的比例分配；全部所选属性都达到上限时，未分配的新点数保留。银行宠物参与宠物小队获得经验升级时也会分配新增点数。宠物的种族自然成长照常计算，自动加点只消耗新增的可分配点数。

人物和宠物方案按角色保存，宠物按唯一编号区分。换携带或银行栏位、存取同一只宠物、重新登录、重载模块或重启服务端后方案保留。交易给其他角色后，新主人自行配置；同栏位换了另一只宠物不会继承旧宠物的方案。

## 服务端实现与验证

- 运行模块：`gmsv/lua/Modules/autoStat.lua`，GBK 编码。
- 编辑源文件：`tools/game-qol/autoStat.lua`，UTF-8 编码。
- 启动注册：`gmsv/lua/ModuleConfig.lua` 中的 `loadModule('autoStat')`。
- 配置保存：已有 `hook_charaext` 表中的 `AutoStatConfigV1`，账号及角色栏位隔离，不新增数据库表。
- 升级事件在原生引擎发放点数之前触发。模块记录旧余额，在引擎计算结束后由 250 毫秒定时器、战斗退出或角色存档事件分配新增点数，因此按实际发放数量处理，兼容当前人物每级 10 点、宠物每级 2 点的设置。
- 配置或舍入进度写入失败时保留原生属性和升级点数，并显示提示。对话回包检查 NPC 距离、场景、战斗状态、窗口编号、会话有效期及宠物身份。

验证使用独立原生服务端、独立 SQLite 和测试角色，没有复制或修改正式玩家数据库。功能、重启和普通/五宠战斗验证分别为 **106、10、41** 项检查；五宠战斗验证覆盖正常战宠及四只替身对应的真实宠物升级、点数分配和替身属性更新。尚未进行实际客户端对话窗口的视觉检查。

银行宠物扩展另有 **55** 项隔离检查，覆盖银行五栏对话、原生升级回调、旧点数保留、换栏位与存取后的身份匹配、重载后配置保留，以及技能学习扣费、取消、重复学习、免费遗忘和换宠后旧窗口失效。公开 Lua API 未提供银行存宠接口，测试使用真实原生宠物，仅替换携带栏及银行栏读取来构造银行列表；实际客户端存取及银行宠物窗口显示仍需复测。技能遗忘回归另通过 **368** 项检查。
