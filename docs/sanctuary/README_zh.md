- `python tools/sanctuary/verify.py`：在独立空 SQLite 数据库和端口 `19230/19231` 验证地图、圣殿93个对象及城内入口、通路连通、菜单、实际 `Char.MoveArray` 行走踩踏往返、邻格不触发、落点不循环、音乐请求、失效战斗状态及真实战斗限制、各模块重载。

- `python tools/npc-overlap/audit_current.py`：复查全服新增 NPC，无同格重叠且可接近。
- `python tools/game-qol/verify_help.py`：验证玩家命令、帮助、README 和编码副本同步。

`python tools/sanctuary/preview.py` 使用客户端真实素材绘制布局，检查当前圣殿对象均不被前景墙面遮挡，预览为 `room_preview.png`。
