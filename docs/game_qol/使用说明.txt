背包与物品
/backpack          查看当前页和各页的空余格数。
/backpack 0        使用第 0 个背包。
/backpack 1        使用第 1 个背包；可用编号为 0、1、2、3。
/bag 2            /backpack 的短命令。
/sort             整理当前背包，合并可堆叠物品，并按类别、物品编号排列。
/sort all         分别整理所有背包，不会把物品移到其他页。
/stack            只合并当前背包中的相同物品。
/stack all        分别合并所有背包。
/identify         免费鉴定所有背包中的未鉴定物品。
/sellstones       出售所有背包中的魔石，按魔石当前标价乘数量加入金币。

常用材料、消耗品及原来可堆叠的非装备物品，堆叠上限提高到 999。
装备保持单件；不同价格、耐久、刻印、道具变量或到期时间的物品不会合并。
金币容量不足时保留整组魔石；没有标价的魔石也会保留。
自动出售只识别原生魔石 ID 123020，不会按名字出售其他物品。
老角色登录或使用命令时，原来 20 格的背包容量会升级到四页共 80 格。

自动功能（命令后接 on 或 off）
/autostack on      自动合并；默认开启。
/autosort on       自动整理全部背包；战斗结束后执行 sort all，默认开启。
/autoidentify on   自动鉴定；默认开启。
/autosell on       自动卖魔石；默认开启。
/autoclock on      有剩余卡时时自动打卡，获得原生双倍经验；默认开启。
/autorepair on     战斗结束后，已装备物品耐久低于 85% 时免费修满；默认开启。
例如 /autosell off 关闭自动卖魔石。
自动功能约每两秒检查一次，战斗或摆摊期间暂停背包和宠物操作。
战后任务每 250 毫秒确认是否已离开战斗；确认后整理全部背包页，并检查人物装备栏 0～7。
修理保持最大耐久，不处理背包中的备用装备；84/100 会修满，85/100 保持原样。
原有明确保存的开关保留，可用 /autosort on 和 /autorepair on 重新开启。
功能开关按角色写入数据库，重登及服务端重启后保留。

宠物
/petbp 0          查看第一个宠物的五项成长档数与总掉档。
/petbp all        查看所有携带宠物。
/petmax 0         将第一个宠物的成长补至该种族满档。
/petmax all       补满所有携带宠物的成长档数。
宠物编号从 0 开始，范围 0～4。
满档操作保留等级、经验及已加点，从后续升级开始按满档成长；不会回炉或重新分配已有属性。

其他命令
/heal             仅支持英文，不带参数；免费清除人物及所有携带宠物的受伤，并补满生命、魔力。
包括生命为 0 的宠物，组队时只治疗自己及自己的宠物；战斗、摆摊或五宠战斗结算期间不能使用。
宠物是否仍在战斗以实际参战名单为准；残留的旧战斗编号或模式不会阻止治疗。
GM 输入 /module reload gameQoL 重载或重启服务端后生效；/help heal 查询用法。
/clock            查看打卡状态与剩余卡时。
/clock on         手动开始打卡；需要剩余卡时。
/clock off        停止打卡，并关闭自动打卡。
/clock full       按 cgmsv.cf 的 fevermax 补满卡时（当前6小时），并立即开始打卡；战斗或摆摊期间不可用。
例如先 /clock off，再 /clock full；GM 用 /module reload gameQoL 重载或重启服务端后生效。
/qol              查看自动功能状态。
/where            查看地图编号和当前位置。
/help             查看当前已加载的全部玩家命令帮助。
/help autorepair  查看单条命令用法；也支持中文别名。
/help gm          查看 Lua 管理员命令，需要 GM 权限。
/fight            原地遇敌，不带数字时使用地图正常随机数量。
/fight 10         指定遇到10个敌人，支持1～10整数；怪物种类和等级来自当前位置，可重复本次选中的怪物。
需存活且不在战斗中，组队由队长使用，地图须允许遇敌；GM 重载 fight 和 gameQoL 或重启生效。
/fivepet on        单人五宠默认开启，条件满足后自动启动；off 关闭并保存，AI 找五宠指挥官设置。
/skillbook         打开永久技能库；中文别名 /技能库。
/difficulty        显示当前难度编号和名称；/difficulty 1～6 切换，中文别名 /难度。
难度默认 6 深渊，组队跟随队长，下场 PvE 生效，战斗中不能切换。
/selfKickOut 账号 密码  校验凭据后断开该账号已在线的角色。
