背包与物品
/backpack          查看当前页和各页的空余格数。
/backpack 0        使用第 0 个背包。
/backpack 1        使用第 1 个背包；可用编号为 0、1、2、3。
/bag 2            /backpack 的短命令。
/sort             整理当前背包，合并可堆叠物品，并按类别、物品编号排列。
/sort all         分别整理所有背包，不会把物品移到其他页。
/stack            只合并当前背包中的相同物品。
/stack all        分别合并所有背包。
/identify         免费鉴定所有背包中的未鉴定物品。
/sellstones       出售所有背包中的魔石，按魔石当前标价乘数量加入金币。

常用材料、消耗品及原来可堆叠的非装备物品，堆叠上限提高到 999。
装备保持单件；不同价格、耐久、刻印、道具变量或到期时间的物品不会合并。
金币容量不足时保留整组魔石；没有标价的魔石也会保留。
自动出售只识别原生魔石 ID 123020，不会按名字出售其他物品。
老角色登录或使用命令时，原来 20 格的背包容量会升级到四页共 80 格。

自动功能（命令后接 on 或 off）
/autostack on      自动合并；默认开启。
/autosort on       自动整理；默认关闭。
/autoidentify on   自动鉴定；默认开启。
/autosell on       自动卖魔石；默认开启。
/autoclock on      有剩余卡时时自动打卡，获得原生双倍经验；默认开启。
例如 /autosell off 关闭自动卖魔石。
自动功能约每两秒检查一次，战斗或摆摊期间暂停背包和宠物操作。
功能开关按角色写入数据库，重登及服务端重启后保留。

宠物
/petbp 0          查看第一个宠物的五项成长档数与总掉档。
/petbp all        查看所有携带宠物。
/petmax 0         将第一个宠物的成长补至该种族满档。
/petmax all       补满所有携带宠物的成长档数。
宠物编号从 0 开始，范围 0～4。
满档操作保留等级、经验及已加点，从后续升级开始按满档成长；不会回炉或重新分配已有属性。

其他命令
/clock            查看打卡状态与剩余卡时。
/clock on         手动开始打卡；需要剩余卡时。
/clock off        停止打卡，并关闭自动打卡。
/qol              查看自动功能状态。
/where            查看地图编号和当前位置。
/help             查看便利命令帮助。
/fight            原有的原地遇敌命令。
