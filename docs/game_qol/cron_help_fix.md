# 定时回调、帮助消息与迷宫出入口修复

- 无在线玩家时，隔离服务端的 `NLG.GetPlayer()` 返回数字 `-1`。`gameQoL` 的两秒回调仅遍历 table，保留逐玩家维护及异常隔离。
- `/help` 与 `/help gm` 总览显示命令用法；完整说明通过 `/help 命令名` 查询。每条帮助消息最多 120 个 GBK 字节，分行保留完整汉字。此前单条说明可以绕过拼接长度限制。此修改消除超长帮助消息，客户端滚轮闪退是否完全解决仍需客户端复测。
- `dungeonconf.txt` 的 34、180、197 三条配置原坐标均被地图物件阻挡，分别调整为 `27102 (16,21)`、`57464 (26,43)` 和 `30001 (444,484)`。没有修改地图图块。原配置备份在 `backups/cron_players_20261011/dungeonconf_before.txt`。

隔离验证：`help_verify.py help` 通过 334 项检查，覆盖消息长度、GBK 汉字边界、完整长说明、动态模块及 GM 权限。`cron_players_probe.lua` 通过 23 项检查，覆盖原生无玩家返回值、非 table 输入、正常玩家维护、单玩家异常、测试角色过滤，以及三个替代坐标的可通行性、无占用和原生传送点创建。验证使用隔离服务端和测试角色，不访问正式玩家数据库。

Lua 修复可由 GM 输入 `/module reload gameQoL` 生效；迷宫配置需正常重启服务端。正式服务端没有停止、重启或热重载。当前战斗基础经验配置为 20 倍。
