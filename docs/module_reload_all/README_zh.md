# 全部模块热重载

已安装 `/module reload all`，只允许 GM 角色使用。

当前正在运行的服务器先在游戏聊天框输入：

```text
/module reload admin
/module reload all
```

第一条从旧版 admin 模块热启用新命令；以后使用第二条即可。无需重启服务器。

重载范围为当前已加载的 Lua 模块。按 ModuleConfig.lua 和 Private/Config.lua 的配置顺序处理，动态加载的其他模块也会重载；保留它们原本的路径和旧式模块选项。

所有模块脚本先进行语法检查；检查失败时保持现有模块运行。加载失败时在聊天框显示模块名，详细错误写入服务端日志；其他模块继续重载。重载会重新初始化模块内部状态。物品 DATA 和框架库文件有各自的加载流程。

沿用模块框架的 NPC 清理和事件解绑；HTTP 模块重载保留已运行的监听服务，并重新绑定 API。兼容正在运行的旧 admin 和旧 HTTP 模块。

原生隔离服务端通过277项检查，包括旧版热启用、权限拦截、连续全部重载、配置顺序、动态模块、现代和旧式模块错误反馈、语法失败保留现有实例、NPC及回调数量稳定、HTTP监听存续。全部重载后 HTTP 实际请求返回200。隔离实例已关闭。未操作真实游戏客户端输入命令。

同一实例还通过247项道路排布检查：10家士兵店员从（144，136）至（162，136），间隔两格，整排前方有连续的可走空位。

源代码在 tools/module-reload；原文件备份在 backups/module_reload_all_20261004/original。
