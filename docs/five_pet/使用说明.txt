单人九宠与宠物 AI — 使用说明

本版安装目录：D:\Games\CrossGate\gmsv。
此次更新 fivePet Lua 与帮助目录。结束战斗后，GM 可用 /module reload fivePet 生效；同步新 /help 说明再执行 /module reload gameQoL，或正常重启「一键启动」生效。

开启与站位
1. 携带5只存活宠物，选定一只主宠，银行前4栏（编号0～3）各放一只存活宠物，离开其他玩家队伍，即可九宠参战；不足时按实际数量。
2. 五宠默认开启，条件满足后自动启动，有几只上几只。
3. 有银行伙伴时，主宠和银行伙伴在前排，人物和随身宠物替身在后排；没有银行伙伴时沿用五宠前排。四个非主宠随身宠物替身各携带对应银行栏的临时战斗宠物，总计最多9宠加1个人物。银行空栏或倒下宠物跳过，不移动其他栏位的配对。
4. 人物和主宠始终由玩家手动操作，Boss战也不接管主宠，其余最多8只宠物默认智能战斗；随身宠物的假人替身每回合只行动一次，护卫、强力护卫和全程防御也只行动一次，不追加第二行动；缺银行伙伴或无银行伙伴时同样适用。银行伙伴遵守原生宠物行动规则。银行原宠保留，最终属性及技能复制到临时战斗宠物，血魔、受伤、经验回写原宠并使用原生升级计算；原宠装备不转移，按原宠最终属性计算。
5. /fivepet off 关闭并保存；/fivepet on 恢复开启。重登、模块重载和服务器重启沿用保存的开关。
6. 银行宠物种类编号映射到原生创建编号，全部替身创建成功后才入队。创建失败暂停相同阵容的自动重试，阵容、主宠、技能或存活状态变化后自动恢复，或输入 /fivepet on 手动重试，避免持续入队、退队音效。

自动技能策略
智能战斗按存活与伤害收益选行动：用当前生命、敌方已学技能效果和可达范围、最近两回合按实际扣血记录的伤害，保守估算本回合及下一回合结束生命。预计本回合会倒下时优先保命；能撑过两回合时优先降低敌方生命，不因固定血量比例或站位强制补血、防御。危险时比较补血、匹配物理或法术威胁的护盾、护卫、明镜止水和防御，考虑耗魔、有效范围、行动先后及护卫转移后的伤害，避免让会倒下的宠物护卫别人。能可靠先手收尾并消除威胁时仍可进攻。敌人倒下、停止攻击、换招或无法命中时重新判断，回合内已行动的敌人不重复计入剩余攻击。普通防御后的物理掉血还原为未防御估计，避免误判威胁消失；战斗结束清空记录。预测是估算，暴击、闪躲和行动先后仍按原生引擎计算。
Boss 遮挡只用于保护安全目标，不强制前排防御：玩家在后排且两边前排遮挡后排近战Boss时，保留敌方挡路宠物，攻击避开会波及它们的十字、全体和随机技能；能安全进攻的前排或后排自动宠物都可用单体远程攻击Boss，预计生命危险时才比较防护行动。Boss能用远程绕过遮挡、挡路宠物倒下或阵型改变后立即重新判断。
人物和主宠始终手动操作，Boss战也不接管主宠；AI只控制其他随身宠物和银行伙伴。
显式全程防御设置保留。自动随身替身每回合只行动一次，银行伙伴遵守原生宠物行动规则；技能必须已学且魔力可支付，不自动使用金钱攻击或破坏装备。

示例：生命400、预计每回合受伤200时，比较补血、护盾、护卫与防御的两回合存活收益；安全时优先输出，预计会倒下时优先保命；护卫会使自己倒下时放弃护卫。

指挥官入口
法兰东门医院附近（223,85）圣殿传送石 → 圣殿（地图60003）→（16,34）五宠指挥官。
菜单列出随身非主宠和银行前4栏宠物，超过一页时选择下一页；仅保留智能战斗、全程防御、查看自动释放逻辑和返回，主宠不列入菜单。
默认智能战斗。旧普攻、技能优先、低血防御等设置统一自动智能战斗，旧全程防御保留；随身宠物的假人替身每回合只行动一次，护卫、强力护卫和全程防御也只行动一次，不追加第二行动；缺银行伙伴或无银行伙伴时同样适用。银行伙伴遵守原生宠物行动规则。可到指挥官改回智能战斗，模式按宠物 UUID 保存。

模式限制与状态同步
只用于单人普通战斗，不支持与其他玩家组队或玩家对战。
额外宠物通过替身加入小队，按实际数量占用最多四个队友名额。
人物倒下时立即结束整场五宠战斗，主宠和额外宠物不再继续行动；开关保持开启，人物恢复且条件满足后自动恢复。
正常胜利后保持开启；逃跑、换主宠、队伍变化、登出或断线时清理替身。
宠物倒下后暂停，恢复后重新满足条件会自动启动。
替身的血量、魔力、受伤和获得经验同步回原宠物，经验沿用原生队伍分配。
银行经验结算：正常胜利后，实际参战且存活的银行前4栏宠物分别获得原生战斗经验，逐只提示所得经验并保存。银行第5栏、未参战或倒下的宠物不分经验。银行原宠不能直接调用原生 Pet.UpPet 升级，因此用临时战斗宠物执行原生升级及种族成长后，回写等级、剩余经验、属性和新增点数；原宠、银行栏位及装备不移动，自动加点继续生效，重复结算不重复发经验。结束战斗后 GM 重载 fivePet、autoStat、gameQoL，或正常重启生效。
人物装配「宠物强化」（技能70）后，经验加成覆盖主宠、其他随身参战宠物和银行前4栏参战伙伴；正常一人一宠也生效。每只宠物先取得自身的原生经验，再按主人当前装配等级的 DATA 比例独立加成一次，向下取整；人物经验不加成。当前 LV1～LV10 为每级增加4%，LV11～LV30 每级再增加2%，LV30 为80%；例如原生经验1000，装配LV30后该宠获得1800。只收录技能库、未装配时不生效，卸下或换装后自动按当前技能结算；未参战或倒下的银行宠物不分经验。结束战斗后由 GM 执行 /module reload fivePet，再 /module reload gameQoL 同步帮助，或正常重启生效。

实现与维护
沿用原生换位的位置编号，将主宠设为前排 5，其他宠物依次设为 6～9，人物设为后排 0。
Lua 的 GetPlayer / GetPlayIndex 在五宠战斗中按实际战斗编号查询，使站位和攻击目标一致。
战斗条目保留原生内部存储位置，保持连续回合、主宠手动操作及原生结算。
退出五宠时清理映射，模块卸载时恢复查询函数。
护卫效果在本回合内保留；所有随身宠物假人替身的第二行动栏统一清空，护卫、强力护卫和全程防御也只行动一次。
