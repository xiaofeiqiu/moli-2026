## 当前服务端生效

DATA 已保存。当前正在运行的主服务端没有被中断；在游戏内用 GM 执行下列命令，可即时同步名称：

```text
/dolua lua/tests/cg71_pet_poc/cg71_pet_poc.lua activate
```

正式名称字段为 4000，使用 GBK 字节写入。脚本核对 Enemy 与 EnemyBase 两个名称；部分更新失败会恢复原名称。从 DATA 正常重启服务端也可生效。

之后生成新宠物：

```text

```

已有宠物及其个人名称会保留，不自动改名。姓名变更之外的数值配置保持原值。
